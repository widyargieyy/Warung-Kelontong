mapping
| No | Komponen UI              | Tabel Database              | Field yang Dipakai                                 | Relasi                                           | Logic / Query                   |
| -- | ------------------------ | --------------------------- | -------------------------------------------------- | ------------------------------------------------ | ------------------------------- |
| 1  | Nama Kasir Login         | `users`                     | `name`                                             | -                                                | `auth()->user()->name`          |
| 2  | Cari Barang              | `barangs`                   | `kode_barang`, `nama_barang`                       | -                                                | Search berdasarkan nama/kode    |
| 3  | List Barang              | `barangs`                   | `kode_barang`, `nama_barang`, `harga_jual`, `stok` | -                                                | Menampilkan barang tersedia     |
| 4  | Tombol Tambah Barang     | `barangs`                   | seluruh data barang                                | `barangs.id`                                     | Masuk ke session/cart           |
| 5  | Keranjang Belanja        | `session/cart`              | temporary data                                     | -                                                | Data sementara sebelum checkout |
| 6  | Nama Barang di Keranjang | `barangs`                   | `nama_barang`                                      | `barangs.id`                                     | Ditampilkan di cart             |
| 7  | Qty Barang               | input user                  | -                                                  | -                                                | User input jumlah               |
| 8  | Harga Barang             | `barangs`                   | `harga_jual`                                       | -                                                | Harga saat tambah cart          |
| 9  | Subtotal                 | session/cart                | qty × harga                                        | -                                                | Per item                        |
| 10 | Total Belanja            | session/cart → `penjualans` | `total_harga`                                      | -                                                | `SUM(subtotal)`                 |
| 11 | Uang Bayar               | `penjualans`                | `uang_bayar`                                       | -                                                | Input user                      |
| 12 | Kembalian                | `penjualans`                | `kembalian`                                        | -                                                | `uang_bayar - total_harga`      |
| 13 | Simpan Header Transaksi  | `penjualans`                | semua field                                        | `users.id → penjualans.user_id`                  | Simpan transaksi utama          |
| 14 | Simpan Detail Transaksi  | `detail_penjualans`         | semua field                                        | `penjualans.id → detail_penjualans.penjualan_id` | Simpan item per barang          |
| 15 | Pengurangan Stok         | `barangs`                   | `stok`                                             | `barangs.id → detail_penjualans.barang_id`       | `stok - qty`                    |
| 16 | Reset Keranjang          | session/cart                | -                                                  | -                                                | Hapus cart sementara            |
